Представляю вашему вниманию легкий и ламповый лаунчер для запуска локально вашей LLM модели и чата с ней. 
Создавал ее исключительно для быстрого и легкого доступа к самой модели т.к. в форме нет ничего лишнего,
Так и к настройкам для работы с ней, для учебы и более наглядной демонстрации влияния настроек на саму модель и генерацию ответов менять их приходится очень часто и лазить по сотне вкладок уже существующих лаунчеров мне было не в кайф)
